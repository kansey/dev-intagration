# Запускт на хосте

Выполнить скрипт генерирующий ssl сертификаты для обращения к kafka.
```
./cert-gen.sh
```

Итоговый набор файлов:
```
ca.crt  ca.key  cert-gen.sh  client.crt  client.csr  client.key  client.p12  kafka.crt  kafka.csr  kafka.keystore.jks  kafka.truststore.jks  README.md
```
