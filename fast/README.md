# Краткое описание

Консольная утилита записывающая в файл бенчмарки по сравнению двух либ, написанных на go по взаимодействия с Kafka.

## Запуск

```
docker compose up --build

docker compose up client
```

Контейнер client запускаем go утилиту записывают метрики по переменной окружения библиотеки.

## Переменные окружения

| Переменная окружения                                             | Значение по умолчанию    | Описание                          |
|:-----------------------------------------------------------------|--------------------------|-----------------------------------|
| KAFKA_BROKERS                                                    | kafka:9092               | Адрес Kafka                       |
| KAFKA_TOPIC                                                      | topic-test               | Название топика                   |     
| KAFKA_ASYNC                                                      | false                    | Отправка сообщение синх или асинх |     
| KAFKA_MSG_COUNT                                                  | 1000                     | Кол-во отправляемых сообщений     |     
| KAFKA_LIB                                                        | franz                    | Используемая либа (franz, sarama) |     
| KAFKA_RUN_CONSUMER                                               | true                     | Запускать ли consumer             | 
| BENCHMARK_FILE                                                   | ../bench/benchmarks.csv  | Путь к файлу для сбора метирк     |     

## Особенности эксплуатации
### Сбор метрик

1. Убедиться что файл benchmarks.csv пустой
2. Выбрать нужную либу в env файле и кол-во отправляемых сообщений.
3. Выполнить

``` 
docker compose up client
```

4. Поменять в env файле либу
5. Повторить п.3
6. перейти в каталог со скриптом построения графика бенчей

```
cd bench
python plot.py
```
